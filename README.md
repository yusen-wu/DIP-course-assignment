# DIP Course Assignments

This repository contains my assignments for the Digital Image Processing course.

## Structure

- `Assignments/01_ImageWarping`: basic image warping and point-based deformation
- `Assignments/02_DIPwithPyTorch`: Poisson image editing and Pix2Pix with PyTorch
- `Assignments/03_BundleAdjustment`: Bundle Adjustment with PyTorch and 3D reconstruction with COLMAP

## Notes

Each assignment folder contains its own `README.md`, code, and related assets.
The current repository includes three assignments covering image warping, deep image processing with PyTorch, and multi-view 3D reconstruction workflows.
